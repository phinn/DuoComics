DuoComics

为 iPhone Duo 而生的漫画阅读器 · 本地 CBZ / ZIP · 双页对开

把一本漫画摊开在两块屏上。DuoComics 直接读取你的 CBZ / ZIP 漫画档案,按原书开本渲染为左右两页,展开时自然对开,合上时外屏保留封面与进度,翻开即回到上次读到的那一页。

App Store 下载

特性

  • 双页对开:展开即得左右两页,像翻开一本真实的漫画
  • 日漫方向:右开本从左向右翻,西漫从右向左,自动跟随
  • 纯本地:导入的漫画档案只存在你的设备里,零上传、零追踪
  • 单页 / 双页 / 条漫三种读法,阅读进度自动保存

隐私

DuoComics 不收集任何数据,详见隐私政策。
